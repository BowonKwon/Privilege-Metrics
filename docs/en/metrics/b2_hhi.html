B · Which trades

Field concentration

0.105Median from 1750
Key point

From 1750 the decade field concentration stays between 0.090 and 0.120; an even split across 17 fields gives 0.059.

Definition
Herfindahl index of field shares among classified grants in each decade, 'other' excluded.
Formula
HHI = Σ (field share)²
How to read it
Higher means grants concentrate in fewer fields. With 17 fields an even spread gives 1/17 ≈ 0.059.
Caveats
The early decades have few grants, so the index swings widely. The index inherits the precision of the field classification (75% weighted).
